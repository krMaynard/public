# Max Insights

[Max Insights](https://www.maxinsights.ai/) is building the data foundation for Physical AI. The company focuses on delivering high-quality data at global scale through a global capture network.

Max Insights works with research partners at Stanford, UCLA, USC, UC Berkeley, and UT Austin.

## About this repository

This is an early public repository for Max Insights. It currently contains a small set of visual assets. More project material and documentation will be added here over time.
